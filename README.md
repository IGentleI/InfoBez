# RSA GUI (вариант 10, N = 35)

Оконное приложение на Python (`tkinter`) для шифрования/дешифрования RSA в рамках лабораторной работы.

## Что реализовано

- Генерация пары ключей RSA, где модуль `n = p*q` имеет **35 десятичных знаков**.
- Автоматический расчёт размера блока `K` (в байтах) на основе `n`.
- Шифрование ASCII-текста в последовательность целых чисел.
- Расшифрование последовательности чисел обратно в ASCII-текст.
- Встроенная проверка на 10 контрольных примерах.

## Запуск

```bash
python app.py
```

## Примечания

- По условию используется кодировка ASCII, поэтому русский текст напрямую не поддерживается.
- Для корректной работы сначала нажмите **«Сгенерировать ключи»**, затем выполняйте шифрование/дешифрование.
