# RSA GUI (вариант 10, N = 35)

Оконное приложение на Python (Tkinter), реализующее шифрование/расшифрование RSA по варианту 10:
- модуль `N` автоматически генерируется как произведение двух простых `P` и `Q`;
- число `N` содержит ровно **35 десятичных знаков**;
- исходный текст обрабатывается как ASCII и разбивается на блоки `K`, где `K` вычисляется из `N`.

## Запуск

```bash
python3 app.py
```

## Функции

1. Генерация ключей RSA (`e`, `d`, `N`, `P`, `Q`, `phi`, `K`).
2. Шифрование введенного ASCII-текста.
3. Расшифрование шифртекста.
4. Контрольная проверка на 10 примерах + замер времени.
